<objective>
Build the generalized bounded paginator `_fetchPages` (the foundation for every other plan in this phase), reduce `_fetchAllPages` to a compatible wrapper, and prove the architecture end-to-end by converting the first broken feed (`_savedTracksFeed`) — the tracer slice for GH #157.

Purpose: JiveLite requests menu blocks of ~200 items (plus XMLBrowser's -10/+10 hack -> quantity=210). Every feed's else-branch currently issues ONE API call capped at the Spotify limit (50 for library), so positions 50..209 stay permanently nil in JiveLite's DB.lua cache -> empty rows. The fix is a bounded multi-page fill starting at the requested offset.

Output: `_fetchPages` + wrapper + converted `_savedTracksFeed` + `t/25_fetch_pages.t`.

    Behavior contract (each point maps to a t/25 test case in Task 2):
    1. `pageLimit` guard (JVL-07): effective page limit is `$args->{pageLimit} || 50` — a 0 from a blocked-endpoint `Client->getLimit()` must never reach the API as `limit=0`. Keep this guard exactly where `_fetchAllPages` already has it.
    2. Keep the `_evictPlayAllCache()` call at sub entry (move it from `_fetchAllPages` into `_fetchPages`).
    3. If `maxItems` is defined and `<= 0`: call `done->([], undef, $startOffset)` immediately without any API call.
    4. Request offset for each page = `$startOffset + scalar(@accumulated)`. Per-request limit = the effective page limit, shrunk to `maxItems - scalar(@accumulated)` when `maxItems` is defined and the remainder is smaller (edge case 4: never over-request the final page).
    5. On fetch failure (`unless ($data)`): call `done->(\@accumulated, $err, $startOffset + scalar(@accumulated))` — this IS the JVL-06 total clamp: a mid-fill error yields partial items with a total that exactly covers what was delivered, so JiveLite never caches nil positions.
    6. After pushing a page's items, trim `@accumulated` back to `maxItems` via splice if it overshot (defensive; API may ignore the shrunk limit).
    7. Track the last-seen total from `extractTotal->($data) // 0` each page.
    8. Continue to the next page only when ALL hold: current page returned >0 items (T-25-01 infinite-loop guard, keep the existing comment), `maxItems` is undef or `scalar(@accumulated) < $maxItems`, and `$startOffset + scalar(@accumulated) < $lastTotal`.
    9. On normal termination compute `$safeTotal`: if the stop reason is maxItems-reached (`maxItems` defined and count == maxItems), `$safeTotal` = the larger of `$lastTotal` and `$startOffset + count` (advertise the true API total so JiveLite requests the next block). For every other stop reason (list exhausted, empty page, shrunken list), `$safeTotal = $startOffset + count` — clamped (JVL-06 / edge case 3). Call `done->(\@accumulated, undef, $safeTotal)`.
    10. Keep the `undef $fetchPage` self-reference cleanup pattern on every terminal path (existing memory-leak guard).

    Preserve/adapt the existing header comment block: document the new keys, the 3-arg done contract, and note that `$safeTotal` is pre-clamped for partial results. Do not restate implementation code in comments.
