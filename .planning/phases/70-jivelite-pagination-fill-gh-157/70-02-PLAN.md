## Conversion pattern (applies to every task below)

Reference implementation: the converted `_savedTracksFeed` from plan 70-01 (read it first). Per feed:
1. Hoist the play-all branch's inline `apiFn` closure to `my $apiFn = sub {...};` above the `if ($isPlayAll ...)`; both branches use it. Closure bodies stay byte-identical.
2. Delete the dead `my $limit = ...` ternary line.
3. Replace the else-branch's single API call with `_fetchPages({ accountId, apiFn => $apiFn, pageLimit => <per-feed, see task>, startOffset => $offset, maxItems => $qty, done => ... })`.
4. done receives `($allItems, $err, $total)`. Error-and-empty (`!@$allItems && $err`) keeps the feed's existing error shape verbatim. Otherwise map `@$allItems` through the feed's EXISTING item pipeline (copied from its current else-branch, including null-guards and greps) and fire `$callback->({ items => \@items, offset => $offset, total => $total })`.
5. Play-all branch (except the `$apiFn` reference) and cache-slice `elsif` stay untouched (JVL-08, edge case 5).
6. Update the sub header comment: bounded multi-page fill for fixed-size block clients (GH #157).
