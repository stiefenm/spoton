  <action>
Create a single-crate Cargo project at spoton-helper/. Cargo.toml: package name `spoton-helper`, edition 2021, one `[[bin]]` name `spoton-helper` path `src/main.rs`, dependencies clap 4 (feature `derive`), serde_json 1, sha2 0.10, anyhow 1, thiserror 2. Add `[profile.release]` with `overflow-checks = true` (a wrapping bug in offset math must abort, never corrupt a binary). Do NOT add protobuf, tokio, reqwest, rustls, ring, or aws-lc-rs — this binary opens no socket.

src/main.rs: clap derive parser named `spoton-helper` with a `#[command(subcommand)]` enum Cmd of three variants: `Patch { --version String, --binary PathBuf }`, `Check { --binary PathBuf, --expect-sha Option<String> }`, `Protobuf { --schema String, --mode String default "decode" }`. Dispatch Check to `check::run`, Patch to `patch::run`, Protobuf to `protobuf_cmd::run`. On any subcommand error, print a single-line JSON error object `{"error": "<message>"}` to stdout and exit non-zero.

src/arch.rs: `read_arch(bytes: &[u8]) -> Option<&'static str>` — validate the 4-byte magic 0x7f E L F at offset 0, read `e_machine` as little-endian u16 at file offset 0x12, map 0x3E → "x86_64-linux", 0xB7 → "aarch64-linux", 0x28 → "armhf-linux" (the SpotOn bindir vocabulary from Soloist.pm @ARCH_MAP), None otherwise. No `object`/`goblin` dependency.

src/check.rs: `run(binary: &Path, expect_sha: Option<String>) -> anyhow::Result<()>`. Read the whole file, compute SHA256 hex via sha2, detect arch via arch::read_arch, detect the Soloist version by scanning the bytes for an ASCII marker matching `soloist ` followed by a dotted version (report it as `soloist_version`, or null if absent), and obtain patch status by calling `crate::patch::scan_status(&bytes)` which returns a struct { lifetime: bool, flac24_gates: [bool; 6], patched: bool }. Emit the D-08 JSON object to stdout with keys: `version` (env!("CARGO_PKG_VERSION")), `arch`, `soloist_version`, `patches` (object with `lifetime` bool and `flac24_gates` array of bools), `sha256`, `patched` bool. When `expect_sha` is provided, add a boolean `sha_matches` field comparing it case-insensitively to the computed hash.

src/patch/mod.rs (STUB for this wave): define `pub struct PatchStatus { pub lifetime: bool, pub flac24_gates: [bool; 6], pub patched: bool }`, `pub fn scan_status(_bytes: &[u8]) -> PatchStatus` returning all-false defaults, and `pub fn run(_version: &str, _binary: &std::path::Path) -> anyhow::Result<()>` returning `anyhow::bail!("patch: unimplemented in this build")`. Wave 2 replaces the bodies; the signatures are the contract check.rs and main.rs depend on.

src/protobuf_cmd.rs (STUB for this wave): `pub fn run(_schema: &str, _mode: &str) -> anyhow::Result<()>` returning `anyhow::bail!("protobuf: unimplemented in this build")`. Wave 2 replaces it.
