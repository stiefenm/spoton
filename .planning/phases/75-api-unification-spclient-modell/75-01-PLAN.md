<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LMS → login5.spotify.com / spclient.spotify.com | Outbound HTTPS carrying credentials-derived material; responses are untrusted binary protobuf |
| credentials.json → Login5.pm | Local secret material (auth_data) read into process memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-75-01 | Information Disclosure | Login5.pm logging | high | mitigate | Never log Bearer token, auth_data, or unmasked username; _mask discipline enforced in Task 2; T-02-10 rule (log path+method only) in SpClient |
| T-75-02 | Denial of Service | ProtobufLite parser on untrusted spclient responses | high | mitigate | Bounded parse loops (pos<len), undef on malformed/overrun, malformed-input unit test in t/34 (Task 1) |
| T-75-03 | Tampering / Elevation | Cross-account cache contamination | medium | mitigate | accountId in every cache key: spoton_login5_token_${accountId}, spoton_spclient_resp_${accountId}_... (CR-01 pattern) |
| T-75-04 | Denial of Service (self) | Shared login5/daemon rate pool (D-09) | medium | mitigate | MAX_CONCURRENT_REQUESTS=2, own rate-limit key, 429 clamp 1-300s |
| T-75-05 | Denial of Service | Blocking HTTP hanging the LMS event loop | high | mitigate | SimpleAsyncHTTP exclusively; no LWP/system in any new module (asserted by absence in code review) |
| T-75-06 | Spoofing | Malformed base62 IDs reaching URL construction | low | mitigate | idToHex charset+length validation before conversion (V5) |
</threat_model>
