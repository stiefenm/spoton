<objective>
Commit the Phase-77 Spike-2 baseline, then switch Soloist Browse onto the bounded
audio endpoint (D-03): ProtocolHandler points at `/stream/track?uri=X&start=Y`,
getNextTrack loses the D-17 gate and re-entry guard, `_signalBoundary` additionally
fires on the raw `'stopped'` playback status (D-02), and the affected tests are
rewritten for the bounded model (D-07). First track of a session serves unbounded —
no boundary is planted until the first `track_changed`/`'stopped'` event (D-01).
Skip/seek rely on the already-implemented flush-disconnect (D-05) — no Perl code
needed for that contract, only the seek URL plumbing.

Purpose: This is the tracer slice of the phase — one production-quality path from
LMS `playlist play spoton://track:ID` through WS `play`, bounded HTTP serving, and
boundary-close EOF back to LMS playlist advance. Once this works, all browseSession
machinery is provably dead (D-06) and can be removed in plan 78-03.

Output: Spike baseline commit + bounded Browse implementation + green rewritten tests.
</objective>
