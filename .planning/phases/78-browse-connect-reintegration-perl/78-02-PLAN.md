<objective>
Make bounded Soloist Browse (plan 78-01) safe to run live: add the echo/confirmation
guard that stops daemon-echoed start/change events from destroying the user's Browse
playlist (RESEARCH Pitfall 1 — the replacement for the removed _emitAllowed
browseSession gate, D-03), and re-key the LMS→daemon pause/unpause/seek forwarding
off the dead browseSession flag onto a bounded-model criterion (Pitfall 4/5).

Purpose: With browseSession permanently 0 since plan 78-01, every daemon event now
reaches the Connect translation, and the old browse forwarding gate never fires.
Without this plan, a Browse play collapses the playlist to one Connect entry, and a
>2s pause kills the bounded HTTP connection via fake-libpulse's POLLOUT timeout.

Output: Live-safe bounded Browse; echo guard + forwarding pinned by t/37 gates.
</objective>
