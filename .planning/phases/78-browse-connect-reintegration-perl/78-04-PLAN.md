<objective>
Switch Soloist Connect onto the same audio contract as Browse (D-03/D-04): Connect.pm
dispatches `spoton://track:ID` playlist entries per track instead of one repeating
`spoton://connect-<ts>` stream, define the new Soloist ownership criterion that
replaces every `connect-`-URL live-check (Pitfall 2), and guard the Phase-27
watchdogs against the new URL shape (Pitfall 3). The librespot Connect path stays
byte-identical (repeating-stream remains correct there; Windows constraint).

Purpose: This completes "ein Audio-Vertrag für beide" — after this plan, Browse and
Connect both stream per-track bounded HTTP with real EOF, and the daemon (Spirc)
remains the sequencer for Connect while LMS follows via track_changed → new entry.

Output: D-04 implemented backend-dispatched; ownership lifecycle pinned by t/37;
watchdogs Connect-safe; full suite green. Phase ends ready for /gsd-verify-work +
Phase 79 E2E UAT.
</objective>
