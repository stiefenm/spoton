# Backend amputation gate (84-12)

Static proof of the backend seam (SEAM-6.3.1/6.3.2): the core must load
without either backend side. Built in 84-12, finished green in 84-13, and run
in CI by 84-10.

## Files

| File | Purpose |
|---|---|
| `librespot.files`, `soloist.files` | The two disjoint manifests. Repo-relative paths, a trailing `/` marks a directory. `Plugins/SpotOn/Helper.pm` is in neither manifest: it is the auth path and therefore core (user decision 2026-10-11). |
| `core.files` | Every `Plugins/SpotOn/**/*.pm` under neither manifest. It is generated by `refcheck.pl --core-files` and committed. refcheck's fence requires every listed module to survive an amputation, and the scanned count to reach this list's size. The fence is derived from this list, never a fixed number. Currently 18 modules (85-15: API/Client.pm removed). |
| `allow.txt` | Range-scoped allow entries, format `path[:start-end]: reason`. Three agreed entries: Credentials.pm (whole, Helper auth path), Backend.pm (whole, string registry), Status.pm:414-419 (`_systemInfo` Helper block). |
| `../amputate.sh <side> [root]` | Removes one side's paths from a throwaway copy. A missing path is red: `MISSING <path>`, exit 1. |
| `../refcheck.pl` | Four modes, described in the next section. |

refcheck.pl modes:

- `--collect <side> [root]`: collects the removed package names before the deletion.
- `<side> [root]`: runs the fence, then the boundary-aware name sweep, then a real `perl -c` of every remaining module against generated LMS stubs.
- `--core-only [root]`: the G2X report over the seven core files. Its name list is the Soloist family only (`Plugins::SpotOn::Soloist`); Helper.pm is core and no backend name (user decision 2026-10-11, 84-13), so the `## Dry run (84-12)` residue table's Helper column is historical.
- `--core-files [root]`: regenerates `core.files`.

A run on a throwaway copy, never on the working tree:

```bash
S=$(mktemp -d); git archive HEAD | tar -x -C "$S"; cp -r tools/ci "$S/tools/"
cd "$S" && perl tools/ci/refcheck.pl --collect soloist . \
        && bash tools/ci/amputate.sh soloist . \
        && perl tools/ci/refcheck.pl soloist .
```

### Matching rules

- A removed name matches only at a package boundary, `\bNAME(?![A-Za-z0-9_])`.
  - `Plugins::SpotOn::Unified::Daemon` matches `isa('Plugins::SpotOn::Unified::Daemon')` and `Unified::Daemon->new(`.
  - It does not match `Plugins::SpotOn::Unified::DaemonManager->`.
- Only non-comment code lines are scanned. Full-line comments, POD and everything after `__END__`/`__DATA__` are skipped.
- Names come from the `package` lines of every `.pm`/`.pl` a manifest entry covers. A directory entry is expanded with File::Find over the tree, never with `git ls-files`, because a `git archive` copy has no `.git`.
  - On the soloist side the names include the vendored `Protocol::WebSocket::*` packages.
- `perl -c` runs against a stub `@INC` hook placed FIRST in `@INC`. The hook synthesises `Slim::*`, `JSON::XS*`, `URI*`, `HTTP::Date`, `Crypt::OpenSSL*`, `Log::Log4perl*` and `Plugins::MaterialSkin*` as AUTOLOAD stubs, so a local LMS install is never consulted. The plugin's `main::` constants are defined as 0. `Plugins/SpotOn/Vendor` joins `@INC` when present, because it is a library root of its own.

### Further controls

- **Stale manifest:** with `Plugins/SpotOn/Unified/DeferBudget.pm` deleted from the copy first, `amputate.sh soloist` prints `MISSING Plugins/SpotOn/Unified/DeferBudget.pm` and exits 1.
- **`perl -c` can fail:** `sub broken { my $x = ; }` was appended to HomeExtras.pm on a librespot-amputated HEAD copy. The run then reports `REFCHECK FAIL Plugins/SpotOn/HomeExtras.pm:0: perl -c: syntax error at ./Plugins/SpotOn/HomeExtras.pm line 203, near "= ;"` and `REFCHECK FAIL librespot hits=1`, exit 1.
- **Clean librespot side:** the same HEAD copy without the break gives `REFCHECK PASS librespot modules=40 allowed=1`. The librespot side of the post-84-12 tree is already clean.
- **Manifest-disjointness gate needs `LC_ALL=C`.** The disjointness check `comm -12 <(... | sort) <(... | sort)` CANNOT fail under the default `de_DE.UTF-8` locale with uutils coreutils 0.8.0: `sort` and `comm` disagree on the order, and comm prints `not in sorted order`. A planted overlap (`Plugins/SpotOn/Unified/Daemon.pm` in both manifests) printed nothing. With `LC_ALL=C` on both `sort` and `comm`, the same planted overlap is printed, and the real manifests give an empty intersection. Any gate (84-10 CI, 84-13) must use the `LC_ALL=C` form.
